# 📊 Análise de Vendas — Data Analytics

## 📌 Sobre o Projeto

Este projeto tem como objetivo realizar uma análise exploratória de dados de vendas, buscando identificar padrões, tendências e informações relevantes para auxiliar na tomada de decisões.

Através do uso de SQL e ferramentas de análise de dados, foram explorados indicadores como faturamento, produtos mais vendidos, desempenho por período e comportamento dos clientes.

---

## 🎯 Objetivos

* Analisar o desempenho das vendas;
* Identificar os produtos com maior faturamento;
* Avaliar tendências ao longo do tempo;
* Gerar indicadores para apoio à tomada de decisão;
* Praticar conceitos de banco de dados e análise de dados.

---

## 🛠️ Tecnologias Utilizadas

* **SQL** — consultas, filtros, agregações e análise dos dados;
* **PostgreSQL/MySQL** — armazenamento e gerenciamento do banco de dados;
* **Excel** — organização inicial dos dados;
* **Power BI** — criação de dashboards e visualização dos indicadores.

## 📈 Análises Realizadas

### Faturamento

* Cálculo do faturamento total;
* Evolução das vendas por período;
* Comparação entre meses.

### Produtos

* Produtos mais vendidos;
* Categorias com maior desempenho;
* Produtos com maior geração de receita.

### Clientes

* Distribuição de clientes;
* Análise por região;
* Identificação de padrões de consumo.
